# Organiza Aí Finanças

Aplicação web de controle financeiro pessoal desenvolvida com Next.js e TypeScript.

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS

## Funcionalidades

- Autenticação de usuários (login e registro)
- Cadastro e listagem de transações financeiras
- Categorização de gastos
- Gráficos e relatórios de movimentação
